# Pinar Care website prototype

Clickable stakeholder prototype for a refreshed Pinar Care website.

The prototype includes:

- Homepage
- Older Persons
- Learning Disabilities & Autism
- Children's Services
- Our Homes concepts for Foxglove House and Skyline Child Care
- Referral, careers and quality journey placeholders

## Preview

The current private Work preview is available at:

https://pinar-care-prototype-2026.realcity1.chatgpt.site

## Run locally

This is a buildless static site. Serve the `dist` directory with any local HTTP server, for example:

```bash
python -m http.server 8000 --directory dist
```

Then open `http://localhost:8000`.

## Content status

Copy, imagery, service details and home-specific information are for stakeholder review. Verify and approve all operational, regulatory and factual content before production use.
